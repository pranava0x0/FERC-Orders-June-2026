What the document says

Co-location · PDF pp. 10–16

Which generator and load can use the agreement?

The generation and load must use the same connection point or a withdrawal point at the same substation and voltage. The agreement does not buy transmission service for the load.

ZG Interconnection Service is not Transmission Service and does not exempt a Transmission Customer from procuring Transmission Service. PDF p. 12
Filed comments: Connecting load and generation

Capacity accreditation · PDF pp. 16–22

How the proposal treats capacity credits

MISO specified where a load-serving entity could use capacity credits associated with a zero-injection resource. It separately proposed penalties if those resources participate as behind-the-meter generation.

all ZRCs associated with a ZG Resource must be used as part of an LSE’s FRAP or RBDC Opt Out PDF p. 20

Queue eligibility · PDF pp. 27–39

Why the request must be ready on day one

MISO proposed a 90-day study and would bar changes to the request after submission. It argued that changes would disrupt the study timetable for other customers.

prohibit modifications to ZG Interconnection Requests after submission PDF p. 34

Responses and related views

State regulators want the export limit to work on the grid as well as on paper

Organization of MISO States · Direct response

OMS conditionally supported the zero-injection agreement. It wanted enforceable limits on a generator exporting power and asked MISO to explain how paired loads and generators would count in capacity and reliability calculations during outages.
