New England states back time for regional deliberation

New England States Committee on Electricity · EL26-72-000 · 2026-08-07

NESCOE, the committee representing the six New England states, supported the requested delay. It wanted the states and stakeholders to be able to examine proposed tariff changes through the region’s existing process.

Eolian wants nearby generation considered for permanent service

Eolian · EL26-72-001 · 2026-09-21

Eolian sought clarification that generation located electrically close to a large load could qualify for permanent limited service if it could constrain grid withdrawals over the long term. FERC dismissed the request because the preliminary order was not final.
