EL26-67-000 · 2026-08-03 · Silver Run Electric, LLC

Motion for Abeyance and Request for Shortened Answer Period and Expedited Treatment of Silver Run Electric, LLC

Silver Run Electric, a PJM transmission owner, moves for a 90-day full abeyance of the E-7 show cause deadline to November 16, 2026, and describes the tariff revisions it expects to propose with PJM through the stakeholder process.

Asks FERC to: Hold the proceeding in abeyance for 90 days from August 17, 2026, extend Silver Run's response to November 16, 2026, shorten the answer period to five days, and rule by August 13, 2026.

Changes the schedule. Seeks to move the E-7 60-day show cause deadline to November 16, 2026, outlining study process and cost recovery revisions it expects to file; FERC granted it on August 14, 2026.

E-7 PJM: Show cause or propose tariff changes in 60 days (p. 7) E-7 PJM: Application / study process (P 6(a), p. 7) E-7 PJM: Cost-recovery agreement (P 77, p. 28)

Key points

  1. Silver Run asks for a 90-day full abeyance to coordinate with PJM and prepare a section 205 filing.
    Silver Run seeks a 90-day full abeyance of the current 60-day deadline to respond to all issues raised in the Show Cause Order PDF p. 1
  2. It expects revisions on large load definition, readiness requirements, alternative transmission technology evaluation and a pro forma service agreement.
    the definition of a large load; readiness and information requirements; the evaluation of alternative transmission technologies; a pro forma service agreement memorializing operational terms PDF p. 5
  3. It expects cost recovery, financial security and rate provisions to mitigate cost shifting, and a reasonable implementation period.
    cost recovery, associated financial security, and rate treatment provisions intended to mitigate cost shifting among transmission customers PDF p. 5
  4. Silver Run says its filing depends on PJM's stakeholder process because it runs none of its own.
    Silver Run does not administer a stakeholder process of its own through which the issues raised in the Show Cause Order could be resolved independently. PDF p. 7
