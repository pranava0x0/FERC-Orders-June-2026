What the document says

Unpaginated filing

FERC dismisses the rehearing requests because a show-cause order is not a final order.

We therefore dismiss the request for rehearing, which concerns a Commission action that is not final and that will be succeeded by further Commission action. Source text

Unpaginated filing

FERC will not clarify the show-cause orders while the cases sit in abeyance.

We do not intend to provide clarification or guidance with respect to the Show Cause Order while the show cause proceeding is held in abeyance. Source text

Unpaginated filing

Eolian sought permanent load-limited interconnection for front-of-meter generation in five of six proceedings.

Eolian requests clarification or, in the alternative, rehearing to provide that electrically proximate generation may access permanent load-limited generator interconnection service Source text
