EL27-11-000 · 2026-11-09 · Exelon Corporation

Exelon answers PJM’s request for more time on its capacity-auction complaint

Exelon answers PJM's November 4, 2026 request for more time and opposition to fast-track processing in the EL27-11 complaint. Exelon says PJM's requested extension is too long for the narrow legal question, supports a shorter extension, and asks for an order well before the May 2027 auction.

Asks FERC to: Limit the extension to December 7, 2026, and issue an order sufficiently in advance of the May 2027 Base Residual Auction.

Parallel proceeding. A procedural answer in Exelon's section 206 complaint on PJM's capacity auction schedule. It does not cite the show cause orders; the link is the shared PJM resource adequacy question.
