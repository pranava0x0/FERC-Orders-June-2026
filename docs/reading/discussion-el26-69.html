Eolian: Eolian wants nearby generation considered for permanent service

EL26-69-001 · 2026-09-21

Eolian sought clarification that generation located electrically close to a large load could qualify for permanent limited service if it could constrain grid withdrawals over the long term. FERC dismissed the request because the preliminary order was not final.

New York Independent System Operator: Who decides if a regulated generation solution will go forward?

EL26-69-000 · 2026-07-20

NYISO explained that if the market and transmission proposals cannot cover a reliability need, it may refer a non-transmission solution to the New York Public Service Commission. The state commission then considers the project and cost recovery. This is NYISO’s description of the process. No state endorsement of a project is involved.
