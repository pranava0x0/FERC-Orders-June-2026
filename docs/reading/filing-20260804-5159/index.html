EL26-67-000 · 2026-08-04 · Constellation Energy Generation, LLC

Answer of Constellation Energy Generation, LLC in response to Transmission Owner's 07/20/2026 Request for Clarification

Constellation answers the Indicated PJM Transmission Owners' request for clarification, opposing any use of the Point of Change in Ownership for co-located load and asking that eligibility terms for electrically proximate load not disqualify large loads.

Asks FERC to: Deny the Transmission Owners' clarification request; if granted, make clear PJM and the owners must propose terms that encourage new transmission services and speedy large load interconnection.

Answers the order. Answer to the Transmission Owners' E-7 clarification request on how large load and electrically proximate load are defined relative to the point of interconnection.

E-7 PJM: Show cause or propose tariff changes in 60 days (p. 7) E-12 NYISO: Define ‘large load’ (P 64, p. 41)

Key points

  1. Constellation says it responds only to the clarification request and calls the rehearing arguments premature.
    Exelon and FirstEnergy’s arguments are premature and barred by Rule 713 of the Commission’s Rules of Practice and Procedure. PDF p. 1
  2. It calls the Point of Change in Ownership request a collateral attack on prior FERC rulings in the co-location dockets.
    This request for clarification is a thinly-veiled collateral attack on the Commission’s previous rulings in Docket Numbers ER26- 1088-000 and ER26-1479-000. PDF p. 2
  3. It asks FERC to clarify that eligibility requirements must not be so prescriptive that they disqualify large loads.
    any eligibility requirements PJM and the Transmission Owners propose in their initial filings must not be so prescriptive as to improperly disqualify large loads PDF p. 2
  4. It also asks that no reference point be used to define electrically proximate large load in a way that undermines speedy interconnection.
    may not use the Point of Change in Ownership, or any other point of reference, to define “electrically proximate large load” in a manner that likewise undermines speedy interconnection PDF p. 2
